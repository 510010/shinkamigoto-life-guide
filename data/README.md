# ごみデータ（令和8年度）

作成：2026-11-07。「上五島くらし案内」MVP ①ごみ のデータ起こし結果。

## 出典

- 新上五島町公式サイト「ごみ収集カレンダー（令和8年度）」
  https://official.shinkamigoto.net/goto_kurashi_full.php?eid=06006&wcid=i00005x5
- 添付PDF 4点（A版 前期／後期、B版 前期／後期）を `../source/gomi/` に保存。
  PDF本文は画像のため、レンダリング画像を目視で読み取った（2026-11-07）。

## ファイル

- `hamlets.csv` — 集落→地区→A／B版の対応（117集落）。公式ページの対応表から転記。
- `categories.csv` — 品目マスタ（7品目）。袋の指定はPDFの凡例から。
- `collection_events.csv` — A版・B版の日別収集イベント（各271件、2026-04-01〜2027-03-31）。
  `../scripts/generate_gomi.py` が規則＋例外から生成する。手入力の日別転記ではない。

## 規則（12か月分すべて目視照合済み）

両版共通：月・水・金＝燃やせるごみ。土日は収集なし。祝日も通常収集。

- A版
  - 火曜：第1週＝有害ごみ＋発泡・トレー／第2〜5週＝缶・びん・ペットボトル
  - 木曜：第1・3週＝燃やせないごみ／第2・5週＝段ボール・新聞・チラシ／第4週＝粗大可燃ごみ
- B版
  - 火曜：第1週＝粗大可燃ごみ／第2・4週＝燃やせないごみ／第3・5週＝段ボール・新聞・チラシ
  - 木曜：第3週＝有害ごみ＋発泡・トレー／それ以外＝缶・びん・ペットボトル
- 例外（両版共通の収集なし）：2026-12-31、2027-01-01（年末年始）

## 検証結果（2026-11-07）

- 有害ごみ・発泡・トレー・粗大可燃ごみ：両版とも年12回、毎月ちょうど1回（異常なし）。
- 燃やせないごみ：両版とも毎月2回、年24回。
- 燃やせるごみ：両版とも年156回（元日の休みを除く月・水・金の全日）。
- 個別日のスポット照合（2026-04-07、05-21、07-30、09-01、11-03）すべてPDFと一致。

## 確認済み事項

- `hamlets.csv` の上五島地区「青木」は、青方とは別の集落として実在することをユーザー本人が確認（2026-11-07）。転記のままで正しい。
