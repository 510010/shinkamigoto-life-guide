# 品目辞典（分別検索用データ）

作成：2026-11-07。「上五島くらし案内」のごみ分別検索のデータ本体。

## 出典

新上五島町「ごみの分け方・出し方（改訂版）」§6 ごみ分別一覧表（冊子20〜29ページ、PDF22〜31ページ）。
PDFは `../source/gomi-guide/guide_tebiki.pdf`。分別早見表（A2ポスター）も同フォルダに保存。

## ファイル

- `items.csv` — 698行。列：
- `name` 品目名（例：蛍光灯の蛍光管）
- `variant` 材質・部分・条件などの内訳（例：金属製・袋に入らない）。なければ空
- `category_id` 収集カレンダーと接続する区分ID。粗大不燃ごみは収集日が燃やせないごみの日のため `nonburnable` に寄せ、元の区分は `table_category` に保持。収集しないごみは `not_collected`
- `table_category` 手引書の表の区分（9区分）そのまま
- `bag` 袋・処理券の指定
- `note` 表の摘要（例：中身を使い切る、完全に洗うこと、販売店・産廃業者など）

## 区分の分布

燃やせる225／燃やせない186／粗大可燃97／粗大不燃93／収集しない46／缶・びん・ペット27／有害16／トレー・発泡5／段ボール・新聞3。

## 作り方と検証

- 表はPDF内で横向きの2段組。グリッド線と文字座標から「○の列＝区分」と摘要を機械抽出（`scripts/parse_tebiki_table.py`）し、品目名・内訳は全10ページを画像で目視して転記・照合した（`scripts/overrides.py`、`scripts/finalize_items.py`）。
- ページごとに視覚側の品目数と抽出行数が一致することを確認。頻出品目のスポットチェック済み（蛍光管＝有害、乾電池＝有害、飲料用ペットボトル＝缶・びん・ペットボトル、食用油・調味料のペットボトル＝燃やせる、等）。
- 注射器・注射針は「収集しないごみ（医療機関へ相談）」として1件に統合。表の脚注文は品目に含めていない。

## 注意

- 手引書は改訂版だが発行年が古い可能性がある。分別ルールが変わっていないか、公開前に町の最新ページと突合すること。
- 一覧表にない品目は表自体の注記どおり「環境課（53-1161）へ問い合わせ」が正規の案内。検索で見つからない場合の表示はそれに合わせる。
