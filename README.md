# 上五島くらし案内

新上五島町の暮らし情報（ごみ収集・ごみ分別検索・船・診療所・防災行政無線）を、
町内在住の世帯担当の方がスマートフォンで素早く確認できるようにした非公式の案内サイトです。

- 公開URL: https://510010.github.io/shinkamigoto-life-guide/
- 個人運営（非公式）です。公式な情報は新上五島町公式サイト・各事業者の公式情報でご確認ください。
- 姉妹サイト: [上五島航路案内](https://510010.github.io/shinkamigoto-route-guide/)（船の詳しい検索・運賃）

## 機能

- 今日のごみ（自宅と実家の2地区分、前日・翌日切替）
- 月に1回だけのレア収集（有害ごみ・発泡トレー・粗大可燃ごみ）までのカウントダウン
- ごみ分別検索（手引書の一覧表698品目。区分・出し方＋自分の地区の次回収集日）
- 今日の船（登録した航路の時刻表。データは上五島航路案内と共通）
- 今日開いている診療所（地区別・通常の診療パターンによる表示）
- 防災行政無線の新着（町の放送を文字で蓄積したアーカイブから）
- 設定は端末内（localStorage）にのみ保存され、外部送信されません

## 構成

- `site/` — 静的サイト本体（HTML/CSS/JS、PWA）。`site/data.json` は生成物ですが、このリポジトリではコミットしてそのまま公開します
- `data/` — 正本CSV（集落・収集イベント・品目マスタ・品目辞典・医療施設）
- `scripts/` — `build_data.py`（data.json生成。ごみCSVのほか、航路案内のデータと防災無線アーカイブを取り込む）、分別一覧表の起こし用スクリプト群

## データの出典

- ごみ収集カレンダー（令和8年度）・ごみの分け方手引書・地区別診療所ページ：新上五島町公式サイト
- 船の時刻表：上五島航路案内プロジェクトのデータ（各船会社公式情報を転記）
- 防災行政無線：町公式の放送ページを毎時巡回して蓄積したアーカイブ

## 更新の流れ

1. `data/` のCSVを編集する（または出典の変化を取り込む）
2. `python3 scripts/build_data.py` で `site/data.json` を再生成する
3. push すると GitHub Actions が GitHub Pages へ公開します
